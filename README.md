# WebsFlow 魔块 · 模块化页面工场

> 面向更多人群的快速建站 / H5 / 线上 PPT / 互动页面工具。
> 零依赖、零构建、零注册 —— 双击 `index.html` 即可使用,数据存在本机浏览器。

## 一分钟上手

```bash
# 方式一:直接打开(支持 file://)
open index.html

# 方式二:起个本地服务
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

1. 首页选择一个场景(官网 / H5 / PPT / 互动故事),模板自动生成完整页面
2. 画布点选模块 → 右侧改内容;左侧「模块」面板拖入新模块
3. 「主题」里换配色字体,「版本」里随时回滚
4. 「导出 HTML」得到单文件页面,上传任意静态空间即可访问

## 四种形态,一套内容

| 形态 | 适合 | 特性 |
|---|---|---|
| 🌐 官网 | 产品落地页、品牌官网 | 桌面画布、吸顶导航锚点、响应式导出 |
| 📱 H5 | 活动邀请、传播页 | 手机竖版画布、底部悬浮按钮 |
| 🖥 线上 PPT | 路演、汇报、课件 | 16:9 幻灯、键盘翻页、全屏放映 |
| ✨ 互动故事 | 品牌叙事、滚动长图 | 入场动画、阅读进度、整屏滚动、热点与问答 |

形态是「渲染适配器」:同一个 hero 模块,在官网里是通栏大图,在 H5 里变成竖版紧凑,在 PPT 里对齐 16:9 版心。

## 架构(理念来源)

```
websflow/
├── index.html          入口(Hub 项目列表 + 编辑器单页应用)
├── css/editor.css      编辑器外壳样式
└── js/
    ├── schema.js       内容模型注册表 —— Sanity/Contentful:内容与呈现分离,字段定义驱动表单
    ├── themes.js       主题系统 —— Elementor 全局样式:改一处全站生效
    ├── runtime-css.js  运行时样式(JS 字符串,画布与导出共用同一份)
    ├── render.js       渲染引擎 —— WordPress 区块:模块 = 内容 × 渲染器 × 形态上下文
    ├── templates.js    场景模板 —— Base44:说清场景即得成品
    ├── store.js        存储层 —— OpenFlow:自动保存心跳、版本快照、撤销重做
    ├── exporter.js     导出器 —— MFlow 适配器:内容包 → 单文件 HTML 可部署产物
    └── editor.js       编辑器 —— Elementor 三栏工作台(模块库 / 画布 / 检查器)
```

设计要点:

- **所见即所得**:画布调用与导出完全相同的 `renderProject()` + `runtimeFn()`,预览即真实效果
- **file:// 兼容**:无 ES Module、无 fetch,运行时样式内嵌为 JS 字符串,双击即用
- **导出即发布**:单文件 HTML 内联全部 CSS/JS 与图片(dataURL),无外部依赖
- **内容可携带**:`.websflow.json` 是纯内容包,可导入回编辑,也可接给其他系统

## 数据与隐私

所有项目存在浏览器 `localStorage`(键 `websflow.v1`),不上传任何服务器。图片上传会在本地压缩为 dataURL 内嵌进项目;大图会显著增加存储占用,建议优先使用图床链接。
