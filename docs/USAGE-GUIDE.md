# WebsFlow 使用指南

> 核心定位 · Features · 具体用例。写给刚开始用 WebsFlow 的投放操盘手、增长团队与独立开发者,
> 也是官网素材源之一。在线 Demo(仅预览,数据随时清理) <https://nownexts.com/webflow/>;
> 正式使用请自部署,见 [部署指南](DEPLOY.md)。

---

## 核心定位

WebsFlow 是面向投放的落地页工场:广告计划已经建好,落地页还得等开发——它把这一步压缩成「选模板、改文案、点发布」。只做单页,把单页做到能直接投放,这是它与建站工具的根本区别:没有全站复杂度,从打开到产出可投放页面以分钟计。

它和「做个好看的页」不是一回事。页面发布只是开始:每一页自带转化埋点,点击漏斗、A/B 实验、块级人群定向(新访客 / 老访客 / 登录态 / UTM 来源)都在数据看板里。投放的人最缺的不是页面,是「哪个块在转化、哪个人群在看」的答案。

WebsFlow 是芭乐派矩阵里**投放人群的进阶单件**:OpenFlow 承接全站资产与长期增长,WebsFlow 只管投放前线——今天建计划,今天要有页,页上有数据。两者账号互通,OpenFlow 登录即可使用。

## Features(按你将真实用到的顺序)

### 1. 起步:从 13 套场景模板里挑一套
产品官网、电商、教育、餐饮、作品集、增长漏斗、活动 H5、课程招生、到店服务、健康、空间、品牌故事、融资路演——每套都是完整可投的成品页,配图来自自托管素材库。想完全自己排,选空白页也行。

### 2. 打开就是画布:44 个成品模块拖进来
信任、痛点、方法、证明、价格、FAQ、倒计时、热点图……8 大分类覆盖落地页叙事全场景。默认文案即可上线,换掉文字就是你的页面;每个模块带布局变体与主题,拖放即调。

### 3. 生产流水线:故事线 → A/B 变体 → 质检 → 交付包
故事线按「信任 → 痛点 → 方法 → 证明 → 行动」排出说服顺序,不用自己发明页面结构;同一页面建多个 A/B 变体;质检跑完再出交付包,把明显的问题拦在投放之前——一条流水线走完,不用在多个工具间来回切换。

### 4. 发布:托管链接或单文件 HTML
登录后点「同步 / 发布」,得到 `https://nownexts.com/webflow/p/<token>` 的托管链接,直接填进广告平台;也可以导出零依赖单文件 HTML——自带 Meta / OG / Twitter Card / JSON-LD 与图片懒加载,社媒分享不发愁。

### 5. H5 形态:移动投放主战场
手机竖版形态、底部悬浮 CTA、进度叙事,一键切换,为信息流与短视频投放而生。

### 6. 千人千面:同一页,不同人看不同块
块级人群定向:新访客看痛点、老访客看优惠、不同 UTM 来源看不同钩子。这是投放场景的核心武器——一条链接吃下多个人群。

### 7. 数据回流:转化目标、看板、分群归因
CTA 转化目标与事件埋点自动记录;转化看板、分群归因、端到端轨迹回答「谁来了、点了哪、为什么转化」;A/B 实验的胜出版本,后台直接发布。

### 8. 增长 Agent 与开放能力
目标编排与页面侧自动化旅程,危险动作必须人审;28 组服务端路由 + MCP server(`mcp/websflow-mcp.js`),能力可被 OpenFlow / PayFlow 调用。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 今天建计划,今天有页(投放操盘手)
1. 打开 <https://nownexts.com/webflow/>,选「电商」场景模板;
2. 画布上逐块改文案:换主标题、价格块、CTA 按钮;左侧模块栏拖一个「倒计时」补紧迫感;
3. 走一遍故事线流水线,跑质检,出交付包;
4. 登录后点「同步 / 发布」,复制 `/p/<token>` 链接,填进广告计划的落地页一栏;
5. 投放跑起来后回转化看板,确认事件埋点正常上报再放量。
**结果**:从打开网页到拿到投放链接以分钟计,不再等开发排期。

### 用例 B · 千人千面:按 UTM 变文案(增长团队)
1. 在页面里给目标块配置人群定向:来源 A 的 UTM 看价格钩子,来源 B 的 UTM 看案例钩子;
2. 给同一块再加一条规则:新访客看痛点版,老访客自动替换为优惠版;
3. 广告计划里分别用两套带 UTM 的链接投放;
4. 投放跑起来后,进后台「人群」页对比两拨人的块级点击差异。
**结果**:一条落地页链接承接多个人群,不用为每套素材单独建页。

### 用例 C · A/B 实验:让数据决定用哪版(增长团队)
1. 对主 CTA 建两个变体:「免费试用」与「立即领取」;
2. 两个变体同时投放,转化目标自动计数,不用手动埋点;
3. 在转化看板看两个变体的转化率与块级点击漏斗;
4. 胜出版本在后台直接发布,替换全量流量。
**结果**:改文案不再靠感觉,每个决定有数据兜底。

### 用例 D · 活动 H5:移动端快速承接(市场 / 运营)
1. 选「活动 H5」模板,切换到手机竖版形态;
2. 开启底部悬浮 CTA 与进度叙事,按叙事节奏排块;
3. 发布托管后,把短链接挂进短信、社群与信息流素材;
4. 有转化目标的活动页,顺手给关键块配人群定向,复用用例 B 的打法。
**结果**:移动投放有专门承接形态,不再拿桌面页硬凑。

## 常见问题

**本地版和在线版差在哪?**
直接打开 `index.html` 可用全部模块、模板与单文件导出;托管发布、转化数据、千人千面等云端能力需登录,或自行部署服务端(见 [部署指南](DEPLOY.md))。在线 Demo 仅用于预览体验,数据随时清理,请勿当作正式环境。

**它能做企业官网吗?**
不能,也不该。多页面站点、CMS、SEO/GEO 属 OpenFlow;WebsFlow 只做单页,不引入全站复杂度。

**能接 CRM 和收款吗?**
收款、订阅、佣金已整体委派 PayFlow;线索档案归 OpenFlow。WebsFlow 专注页面与转化数据本身。

**免费版够用吗?**
免费版可用:3 个云端项目、1 个发布页、AI 出页 20 次/日;专业版 ¥39/月起(100 项目 / 50 发布页 / 200 次 AI),现行配额见 docs/PRICING.md。

**H5 和桌面页要分开做吗?**
不用。编辑器内一键切换 H5 形态;信息流与短视频投放建议直接用竖版形态、底部悬浮 CTA 与进度叙事。

## 进阶

- 线索与转化要接住 → 回到 **OpenFlow**:CRM 管道与自动化画布承接后续(账号互通,免注册);
- H5 与桌面页共用同一个编辑器,切换形态即可复用已有叙事结构;
- 投放验证出的优质单页,沉淀为模板与模块,下一轮出页更快;
- 想让 OpenFlow 或自己的 agent 调用出页能力 → 工具 API(28 组服务端路由)与 MCP server 已开放;
- 导出的单文件 HTML 可直接嵌入 OpenFlow 站点,作为全站资产的一部分。
