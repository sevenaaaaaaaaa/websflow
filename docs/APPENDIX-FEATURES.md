## 一、开始之前:三种打开方式

### 首页(项目列表 + 场景入口)

![首页](screenshots/01-home.png)

**这是什么**:启动 WebsFlow 看到的第一个页面。顶部是品牌区与全局动作(语言切换、登录/注册、AI 生成页面、导入项目、新建页面),下方是已有的本地项目列表与场景模板入口。

**怎么用**:

- 第一次使用:点「＋ 新建页面」,或直接在下方场景卡片里选一个;
- 老用户:点项目卡片继续编辑;卡片右侧垃圾桶按钮删除项目;
- 「⬆ 导入项目」接受 `.websflow.json` 内容包,用于迁移或备份恢复。

### 新建页向导:形态 × 模板 × 命名

![新建页向导](screenshots/02-new-page-wizard.png)

**这是什么**:创建项目的唯一入口,分三步——① 选择形态(官网/H5/线上 PPT/互动故事),② 选择模板(10 套行业成品 + 空白开始),③ 命名。

**怎么用**:

- 形态决定画布比例、可用模块与运行时行为,创建后不可改(如需切换形态,新建后用 JSON 导入搬运内容);
- 模板自带完整文案与配色,选最接近的场景再改字,比空白起步快得多;
- 登录后,向导底部会出现「🌐 云端模板」:别人发布到模板库的页面会列在这里,一键引用。

## 二、三栏工作台与顶栏工具

### 编辑器全景

![编辑器全景](screenshots/03-editor-overview.png)

**这是什么**:编辑器三栏布局——左栏是功能面板(模块/大纲/页面/片段/分群/自动化/AI/市场/主题/版本),中间画布所见即所得,右侧检查器展示当前选中模块的全部可编辑字段。

**怎么用**:

- 左栏点击模块即插入画布;画布上点击任意模块,右侧检查器立即出现它的字段表单;
- 画布内每个模块悬停会浮出工具条:上移/下移、复制、删除、收进容器;
- 顶部「● 已保存」是自动保存心跳——改动即存 localStorage,断电不丢。

### 多设备预览:桌面 / 平板 / 手机

![平板预览](screenshots/14-device-tablet.png)

![手机预览](screenshots/15-device-mobile.png)

**这是什么**:顶栏设备切换按钮,即时改变画布宽度,模拟目标设备上的渲染效果。

**怎么用**:

- 投放页务必切到「手机」过一遍:H5 形态的画布本身就是手机竖版;
- 设备预览只影响编辑视区,不改变内容;导出页会自适应真实设备。

### 界面语言:中文 / English

![英文界面](screenshots/41-editor-english.png)

**这是什么**:顶栏 EN/中 按钮一键切换界面语言。后台与编辑器全部界面文案均已双语化,内容数据不受影响。

## 三、左栏十大面板

### 1. 模块库

![模块库](screenshots/04-left-blocks.png)

**这是什么**:全部内容模块的货架,按「结构 / 转化 / 社交证明 / 表单 / 展示 / 互动 / 幻灯 / 插件」分类。每个模块显示图标、名称与悬停提示。

**怎么用**:点击插入到当前选中模块之后;或直接拖拽到画布目标位置。只显示当前形态可用的模块(如 PPT 形态下会出现「幻灯」分类)。

### 2. 大纲

![大纲](screenshots/05-left-outline.png)

**这是什么**:整页模块的层级列表,等于页面的目录。

**怎么用**:点击条目选中画布模块;拖动排序;条目右侧 ✕ 删除(有确认)。页面模块多时,用它定位比在画布里翻找快。

### 3. 页面(多页站点)

![页面管理](screenshots/06-left-pages.png)

**这是什么**:官网形态支持一个项目多个页面(首页 + 子页),此面板管理页面列表、排序与删除。

**怎么用**:「＋ 添加页面」新建;每页可单独设置 slug(访问地址)与 SEO 信息;托管发布后子页通过 `/webflow/p/<token>/<slug>` 访问。

### 4. 片段(版式预设)

![片段](screenshots/07-left-presets.png)

**这是什么**:内置版式预设与自定义片段。内置预设调的是全局版式参数(容器宽度、圆角、阴影等);自定义片段可以把你调好的模块组合存起来复用。

**怎么用**:选中若干模块 → 保存为片段 → 下个项目一键插入;内置预设点一下即生效,可随时撤销。

### 5. 分群(千人千面)

![分群](screenshots/08-left-segments.png)

**这是什么**:人群分群管理。分群 = 一组访客判定规则(新老访客、登录态、UTM、设备、国家、时段),建好后可在任意模块上引用,实现块级人群定向。详见[第八节](#八千人千面与分群)。

### 6. 自动化(页面侧旅程)

![自动化](screenshots/09-left-automation.png)

**这是什么**:页面内自动化的编排入口——例如「停留 30 秒后弹出优惠券」「滚动到价格表时高亮 CTA」这类页面侧旅程规则。

**怎么用**:新建规则 → 选触发条件(时间/滚动/点击)→ 配置动作(弹层/高亮/替换文案)→ 保存后导出页自动携带执行逻辑。

### 7. AI 助手

![AI 面板](screenshots/10-left-ai.png)

**这是什么**:AI 能力面板:文案改写、整页生成建议、模块补全。需要配置模型供应商;未配置时明确提示降级,不会假装成功。详见[第十二节](#十二ai-能力与任务库)。

### 8. 市场

![市场](screenshots/11-left-market.png)

**这是什么**:模块市场入口——浏览/安装社区模块插件,管理已安装插件与收藏。详见[第十三节](#十三开放能力api--mcp--插件)。

### 9. 主题

![主题](screenshots/12-left-theme.png)

**这是什么**:全局主题:8 套配色预设 + 风格档 + 字体搭配 + 版式参数。详见[第六节](#六主题系统)。

### 10. 版本

![版本](screenshots/13-left-version.png)

**这是什么**:版本快照列表。每次结构性改动都可以留快照,支持一键回滚。

**怎么用**:大改前手动打一个快照;改坏后进此面板对比并回滚。配合顶栏撤销(⌘Z)使用,小改动撤销、大改动回滚。

## 七、导出与发布

WebsFlow 有三条"上线"路径,按场景选:

| 路径 | 产物 | 适合 |
|---|---|---|
| 导出 HTML | 单文件 `.html` | 任意静态空间 / 对接广告主自己的托管 |
| 导出 JSON | `.websflow.json` 内容包 | 项目迁移、备份、批量复制 |
| 云端托管 | `https://域名/webflow/p/<token>` | 自带数据回流与千人千面的正式投放 |

### 导出单文件 HTML

导出动作直接下载文件(无弹窗),文件自带 SEO Meta、OG/Twitter Card、JSON-LD、图片懒加载,双击即可打开,与画布所见完全一致。

![导出页预览](screenshots/19-preview-export.png)

**怎么用**:顶栏「⬇ 导出 HTML」;上线前建议先点「👁 预览」在新窗口看一遍真实渲染效果(预览与导出走同一构建函数,所看即所得)。

### 托管 SSR 发布页

![托管发布页](screenshots/22-hosted-ssr.png)

**这是什么**:登录并同步后,「发布」会把项目变成一个服务器直出的页面(服务端渲染,URL 稳定,可挂广告平台)。托管页与导出页共用同一渲染内核,还额外支持:

- 服务端人群判定(与浏览器端逻辑同源,不受浏览器限制);
- 事件回传:pageview / cta_click / form_submit 自动上报;
- A/B 与版本切换(配合后台「落地页」页使用);
- 子页路由 `/webflow/p/<token>/<slug>`。

**怎么用**:编辑器「☁️ 同步」上传项目 → 后台「落地页」或编辑器「发布」获取链接 → 把链接填进广告平台。取消发布后链接立即失效(访客看到友好下线页)。

## 八、千人千面与分群

**这是什么**:WebsFlow 的差异化能力。传统页面"千人一面",这里可以给**每一个模块**配置人群定向,让同一页面对不同人呈现不同内容。

**判定维度**(组合使用):

| 维度 | 取值 | 典型用法 |
|---|---|---|
| 访客身份 | 新访客 / 老访客 | 新人看 0 元体验,老人看进阶套餐 |
| 登录态 | 已登录 / 未登录 | 已登录隐藏注册引导 |
| UTM 来源 | 任意字符串 | `utm_source=google` 的访客看搜素场景文案 |
| 设备 | 手机 / 桌面 | 移动端突出一键拨号 |
| 国家 | 任意国家码 | 多地区投放差异化合规文案 |
| 时段 | 如 `9-18` | 工作时间显示"立即咨询",夜间显示"留言回电" |

**怎么用**:

1. 左栏「分群」新建分群,组合上述规则(截图见[第三节](#5-分群千人千面));
2. 画布选中任意模块 → 检查器底部「使用分群(控显示)」→ 选择分群或自定义规则;
3. 导出页在浏览器端判定;托管页在服务端判定(逻辑同源,结果一致);
4. 数据回流时事件自动携带分群标记,后台可按分群拆解转化。

## 九、数据与转化

### 事件模型

页面自动回传三类事件,也接受外部系统投递的自定义事件:

| 事件 | 触发 | 说明 |
|---|---|---|
| `pageview` | 页面浏览 | 托管页自动上报 |
| `cta_click` | 行动按钮点击 | 模块内 CTA 自动绑定 |
| `form_submit` | 表单提交 | 生成 `lead` 线索事件 |

外部事件经 `POST /webflow/api/ingest` 投递(需 API 密钥 + ingest 权限,幂等去重),自动参与实时看板 / 分群归因 / A/B 计量。

## 十、生产流水线

**这是什么**:把"批量出页"组织成生产线的后台模块:**故事线(叙事骨架)→ A/B 变体批量生成 → 质检(文案/合规/链接检查)→ 交付包**。

## 十三、开放能力:API / MCP / 插件

### REST API(27 组路由)

全部后台能力程序化可操作,登录态走 Bearer Token,机器调用走 API 密钥(可限权):

| 路由组 | 能力 |
|---|---|
| `users` | 注册 / 登录 / 资料 |
| `projects` | 项目 CRUD、发布、版本、人群规则总览 |
| `events` | 事件上报、实时流、统计 |
| `ingest` | 外部系统事实事件投递(幂等) |
| `goals` / `metrics` | 转化目标编排、指标查询 |
| `identity` | 访客身份打通(vid ↔ uid ↔ PayFlow) |
| `segments`/`automation`(经 projects) | 分群与页面自动化 |
| `growth` / `patterns` / `lessons` | 增长建议、模式库、经验库 |
| `produce` | 生产流水线(故事线 / 变体 / 质检) |
| `templates` / `plugins` | 云端模板与模块插件市场 |
| `billing` / `referral` | 计费、邀请返佣 |
| `tasks` / `scheduled` / `alerts` / `notifications` | 任务、定时、告警、通知 |
| `actions` / `review` / `webhooks` | 跨系统动作(OpenFlow/PayFlow)、人审闸门、外发回调 |
| `tools` / `capabilities` / `selfcheck` | 工具注册、能力目录(41 条)、系统自检 |
| `ai` / `layout-presets` / `lessons` | AI 网关、版式预设、经验沉淀 |

### MCP Server

内置 MCP(`mcp/` 目录):AI Agent(如 Claude)可直接列出项目、读取看板、创建页面——WebsFlow 的全部能力对 Agent 生态开放。

### 模块插件

插件 = 字段 schema + HTML 模板,几十行 JSON 即可注册一个自定义模块:

```js
WF.registerPluginBlocks([{
  block_type: "my-block",
  name: "我的模块",
  description: "一句话说明",
  fields: [{ key: "title", label: "标题", type: "text" }],
  template: "<h2>{{title}}</h2>",
}]);
```

字段类型支持 text / textarea / list / image;模板支持 `{{字段}}` 与 `{{#列表}}…{{/列表}}` 语法,输出自动过 XSS 净化。安装到市场后,其他用户一键使用。

## 十五、快捷键与实用细节

| 快捷键 | 作用 |
|---|---|
| `⌘Z` / `Ctrl+Z` | 撤销 |
| `⇧⌘Z` / `Ctrl+Shift+Z` | 重做 |

(输入框聚焦时快捷键自动让位;更多快捷键在路线图上。)

实用细节:

- **自动保存**:改动即存,顶栏「● 已保存」即心跳;断电不丢内容;
- **file:// 兼容**:零依赖设计,双击 index.html 即可用,是特性不是缺陷;
- **字体栈一律单引号**:在检查器填字体名含引号时,系统已处理,无需手动转义;
- **数据归属**:本地数据在浏览器 localStorage,云端数据在你自部署的数据库(单文件,直接备份)。
