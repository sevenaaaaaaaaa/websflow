**面向投放的落地页工场** —— 单页 · 数据 · 千人千面 · 模块化 · H5。POSITIONING.md 的「三不做」继续有效。

## 三条主线(未完成项)

### A · 交付力

- [x] 10 套开箱即投行业模板
- [x] 注册 → 首发时长进看板
- [ ] 托管页 Lighthouse ≥ 90(实测,不改口径)
- [ ] 出页中位数被真实用户打到 ≤ 10 分钟

### B · 商业化

- [x] 年付 SKU 代码 + PayFlow 映射 + 目录/升级动线
- [ ] 一笔真实付费全链路(注册 → 升级 → 收款 → 权益 → 周报对账)
- 团队档、流量配额:仍按原前置条件,不提前卖

### C · 增长

- [x] 内部 2 页进案例墙
- [x] 一键设立 3 个默认增长目标
- [ ] 10 个种子用户,周活 ≥ 6
- [ ] 公开发布与 CVR 可核验数字(必须来自 CDP)

## 节奏

| 时间 | 只验收这些 |

| 本周 | 真钱一笔 + 种子开口(不写新平台接口) |

- 批次发布:每周 1–2 个带完整 CHANGELOG 的版本
- 服务器线 = 代码真源;本地线 = 镜像、规划与核查;不并行改同一文件
- 对外转化数字必须来自 CDP
- 发布前 pull 镜像;node_modules / db / 日志 / 密钥不入库
