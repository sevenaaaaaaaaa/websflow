## 二、埋点规则（学习自现有页面）

### 1) 站点 CDP（OpenFlow，现有页面统一使用）
- SDK：`<script src="/assets/cdp-track.js" data-api="/api/cdp.php" data-autotrack="1"></script>`
- 自动采集：`page_view` / `scroll_depth` / `element_click` / `outbound_click` / `form_submit` / `time_on_page` / `js_error` / `site_search`
- 手动调用：`CDP.track('event_name', {...})`、`CDP.identify({email,name,phone})`、`CDP.setUserProperties({...})`、`CDP.pageView({...})`
- 点击约定：任意 `<a>` / `<button>` / `[data-track-click]` 自动上报 `element_click`；本交付页面在 CTA 上输出 `data-track-click="<转化目标>"`，让"点击"与"转化目标"同名对齐
- 上报：`FormData`（`action=track_batch`、`events`、`visitor_id`）→ `POST /api/cdp.php`（sendBeacon，5 条或 5 秒批量）
- 已验证：批量上报返回 `{"ok":true,"count":2}`

### 2) WebsFlow 转化埋点（页面自身的转化看板）
- 曝光：页面加载即上报 `view:<projectId>`（每会话一次）
- 点击：CTA 元素带 `data-goal="<转化目标>"`，点击 `sendBeacon /webflow/api/events`
- 携带 `seg`（命中的分群标记：设备 / UTM / 新老 / 登录），用于**分群转化归因**
- 携带 `vid`（访客标识，localStorage `wf_vid`）与 `src`（来源：`utm_source` → `utm:xxx`、否则引荐域 `ref:host`、都没有则「(直接访问)」）
  → 实时看板的**在线访客数**（近 5 分钟按访客去重）与**来源分布**（近 30 分钟）由此而来
- 已验证：`lp-diagnosis-cta` 点击已入看板；分群表出现 desktop / mobile 行

### 3) 表单（线索）
- 提交 → `POST /webflow/api/automation/lead`：存 `leads` 表 + **写入 OpenFlow 待办**（CRM/旅程归 OpenFlow）+ 通知管理员
- 同时调用 `CDP.track('form_submit', {...})`，与现有页面事件名一致
- 已验证：线索「李四」已生成 OpenFlow 待办（high）

## 三、后续页面如何复用同一套埋点

在编辑器「主题与发布 → **埋点与统计**」：
1. 勾选「启用站点 CDP 埋点」（默认注入 `/assets/cdp-track.js` + `/api/cdp.php`）
2. 如需识别用户，在「自定义脚本」里写：`CDP.identify({ email: '...' })`
3. CTA 模块填「转化目标 ID」→ 导出/托管页自动带 `data-goal` 与 `data-track-click`

## 四、发布与回滚

- 重新发布：编辑器 → 主题与发布 → 同步/发布，或在后台「落地页 → 发布」；同一 token 地址内容即时更新
- 取消发布：后台「落地页 → 取消发布」（30 秒内全网失效）
- 版本：编辑器「版本」面板可回滚到任意快照

## 五、页面侧自动化（多步旅程）

编辑器「自动化」支持**多步旅程**:一条规则 = 触发 + 动作步骤序列,每步可设**延迟(秒)**与**执行前条件**(如「仍未点击」)。

内置 4 个旅程模板一键创建:

| 模板 | 触发 | 步骤 |
|---|---|---|
| 首访引导 | 停留 20s 且未点击(新访客) | ① 优惠条 ② 延迟 15s 弹窗(仍要求未点击) |
| 离站挽留 | 退出意图 | ① 弹窗挽留 ② 延迟 15s 补发优惠条 |
| 深读催单 | 滚动 70% 且未点击 | ① 优惠条 ② 延迟 20s 弹窗 |
| 广告来源定制 | UTM 命中 ads | ① 广告专属优惠条 |

- 运行时按顺序执行、延迟累加;某步条件不满足只跳过该步,不影响后续
- 同会话每条只触发一次(可勾选重复)
- 已验证:3 秒出优惠条、+4 秒出弹窗(线上实测)

## 六、主题与版式令牌(可视化调参)

编辑器「主题 → 版式与间距」可调,改动即时生效并同步到已发布页面:

| 控件 | 范围 | 作用 |
|---|---|---|
| 密度快捷 | 紧凑 / 标准 / 宽松 | 一次设定段间距 + 栏距 + 卡片内边距 |
| 段落间距 | 24–200px | 所有模块的上下留白(派生紧凑/宽松/主视觉/H5 各档) |
| 左右边距 | 8–72px | 全站左右安全边距(窄屏自动收窄) |
| 栅格栏距 | 6–64px | 卡片网格、列表、图文分栏的间距 |
| 卡片内边距 | 8–64px | 卡片/面板内边距(派生紧凑与面板两档) |
| 卡片圆角 | 0–28px | 全站圆角(按钮、卡片、面板等比派发) |
| 版心宽度 | 1040 / 1120 / 1200 / 1280 | 内容最大宽度 |
| 阴影强度 | 无 / 轻柔 / 标准 / 厚重 | 卡片与面板投影 |

- 出厂值为 **76 / 24 / 22 / 26 / 1120 / 标准**,与升级前视觉一致
- 令牌会内联进单文件导出与托管页,因此导出文件与线上页面表现一致
- 「重置为预设值」可一键回到出厂版式
